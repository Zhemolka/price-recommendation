# Рекомендация цен по предложениям конкурентов

## Запуск

Пример расчёта:

```bash
python starter.py
```

Для данных из примера ожидаются `price = Decimal("4728.00")` и `decision = "APPLY"`.

Автоматические тесты:

```bash
python -m unittest -v
```

## Правила расчёта

1. Получение предложений ограничено тайм-аутом (по умолчанию 2 секунды). При исключении, тайм-ауте или `status != "success"` возвращаются текущая цена и `HOLD`.
2. Учитываются только конкуренты с известным сроком доставки не более 6 дней. Собственный магазин `MYSHOP` исключается без учёта регистра.
3. Если подходящих предложений нет, цена не меняется (`HOLD`), в том числе когда текущая цена ниже минимально допустимой.
4. Минимальная цена конкурента уменьшается на 1,5% и округляется **вниз** до копейки. Итоговая рекомендация не может быть ниже `min_price`.
5. Если отличие рекомендации от текущей цены **строго больше 30%**, возвращается `REVIEW` — цена требует ручного подтверждения. При изменении не более 30% возвращается `APPLY`.

Для денежных значений используется `Decimal`, округление выполняется с `ROUND_DOWN`.

### Результат

`recommend_price(fetch_offers, current_price, min_price, timeout_s=2.0)` — асинхронная функция. Возвращает словарь:

- `price` — рассчитанная или сохранённая текущая цена (`Decimal`);
- `decision` — `APPLY`, `REVIEW` или `HOLD`;
- `reason` — причина решения.

`APPLY` разрешает применение цены, `REVIEW` требует ручной проверки, `HOLD` сохраняет действующую цену. Функция **только рассчитывает рекомендацию**, не обновляет реальные прайсы.

## Структура проекта

- `starter.py` — функция `recommend_price` и пример асинхронного источника данных.
- `test_starter.py` — три теста на `unittest.IsolatedAsyncioTestCase`:
  - стандартный расчёт с фильтрацией предложений;
  - тайм-аут источника с сохранением текущей цены;
  - граничное изменение ровно на 30%, при котором разрешён `APPLY`.
